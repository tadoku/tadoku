Tadoku Paper · Button grammar · Study 11

Names should describe emphasis, not intent.

Default, primary, and ghost describe visual hierarchy. Danger modifies tone. “Close” is an action label whose visual treatment depends on where it appears.

Design system

Human-facing name: Tadoku Paper.

Package

React package: paper-ui; never Next-specific.

Migration

One complete application at a time; no mixed v1/v2 UI inside an app.

01 · Visual hierarchy

Three variants cover ordinary actions

There is no separate secondary variant in this proposal. Default already fills that role, which keeps both the vocabulary and the visual hierarchy smaller.

Default

Neutral action

Routine, reversible, or lower-priority actions: Cancel, Close, Edit, Back.

class="btn"
Primary

Preferred next action

The single action the interface most wants completed: Save, Submit, Join.

class="btn primary"
Ghost

Interface chrome

Low-emphasis controls, toolbars, back actions, and compact close buttons.

class="btn ghost"
Loading state

Composable state

Loading combines with any hierarchy. The class draws it; attributes carry behavior and meaning.

class="btn primary loading"
Danger tone

Destructive, lower emphasis

Use when deletion is available but not the dialog’s intended next step.

class="btn danger"
Primary + danger

Destructive confirmation

Reserved for a dedicated confirmation flow where destruction is the explicit next action.

class="btn primary danger"

02 · Is default the close button?

Sometimes. Placement decides.

A footer button participates in the action hierarchy. A top-right × belongs to window chrome and should visually recede.

Edit reading

The footer uses a default Cancel button beside the primary Save action.

Reading details

The top-right × is a ghost icon-only button with an accessible name.

Recommendation: do not create a `close` visual variant. “Close” is purpose; default or ghost is presentation. This prevents purpose-specific variants such as `save`, `edit`, or `back` from multiplying the API.

03 · Variant versus tone

Danger modifies the hierarchy

Keeping danger independent lets the same destructive action appear quietly in a menu or strongly in its final confirmation.

04 · Class and component parity

Two APIs, one CSS implementation

Class API · always supported

  className="btn primary loading"
  aria-busy="true"
  disabled
>Saving</button>
React API · optional convenience
<Button>Close</Button>
<Button variant="primary">Save</Button>
<Button
  variant="primary"
  loading
>Saving</Button>

05 · Paper architecture

React, but never Next.js-specific

Package

Tadoku Paper

paper-ui
  • React and React DOM as peer dependencies.
  • No `next`, `next/image`, `next/link`, or `next/font` dependency.
  • Exports components, tokens, CSS recipes, font assets, icons, and an optional Tailwind preset.
  • Router-specific links use the public class API or a caller-supplied React element.
